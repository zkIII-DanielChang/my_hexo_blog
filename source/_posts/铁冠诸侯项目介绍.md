## 这是个什么游戏

《铁冠诸侯》是一个受 CK3（Crusader Kings III）启发的**回合制大战略游戏**：你扮演一个中世纪王国的统治者，管领土、收税、征兵、分封、宣战，还要熬过国王的生老病死和继承危机。

它最特别的地方是**交付形态**——整个游戏是**一个 HTML 文件**。没有构建工具，没有 npm 依赖，没有后端；把它丢到任何静态服务器（比如这个博客）上，点开就能玩，手机竖屏单手可操作。

## 技术拆解

{% hideToggle 点开看：单文件里的四层画布与数据驱动 %}
整个游戏跑在一个文件里，靠的是清晰的分层：

**渲染层**：四张叠放的 Canvas——地图层（低频重绘的省份/边界/文字）、单位层（逐帧的兵牌）、特效层（选中呼吸动画）、UI 层（悬停高亮/移动范围）。每层独立脏标记，相机平移缩放只在需要时重绘。

**数据层**：一切皆 `GameState`。省份是多边形 + 邻接表，国家是省份集合 + 财政，人物靠 `liegeId` 串成封臣链：

```json
{
  "character": {
    "name": "亨利·维斯特兰",
    "title": "duke",
    "age": 43.25,
    "dip": 12, "mar": 17, "ste": 9,
    "traits": ["勇猛", "精明"],
    "liegeId": 3
  }
}
```

顺着 `liegeId` 往上爬，就是"伯爵→公爵→国王→皇帝"的完整链条；人物死亡时，头衔、直辖领地和所有附庸的效忠对象自动指向继承人。

**存档层**：地图几何**不存档**——它由种子确定性重建；存档只序列化可变状态（归属、建筑、人物、外交矩阵、军队、战争、财政），一份档 27KB 左右，损坏了也能静默降级新开一局。
{% endhideToggle %}

几个我自己比较得意的设计决策[^1]：

- **直辖领地（Demesne）**：国王不会把所有土地封出去——首都圈是王室直辖，公国首府是公爵直辖。这不只是拟真，它让"直辖 vs 分封"变成了真正的策略权衡。
- **封臣义务折算**：征兵时直辖领全额出兵、封臣领只出 60%，把封建契约的味道做进了数值里。
- **每回合自动存档 + 页面卸载兜底**，外加删档时的禁写标志——这个 flag 是被真实 bug 教育出来的：删档后 `location.reload()` 触发 `pagehide` 兜底存档，刚删的档瞬间被写回。

[^1]: 顺便炫一下 markdown 脚注语法，Hexo 原生支持。本文里的彩色提示框、标签页、时间线、折叠块用的都是 Hexo 外挂标签（tag plugins），写法形如 `{% note %}` … `{% endnote %}`，不是标准 markdown，但正是 Hexo 的乐趣所在。
